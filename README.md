### Research and Computational Biology

* **Syrinx:** A nine-stage computational pipeline applying genomic sequence-analysis methods to birdsong encoded as symbolic sequence data. Built in Python and R, integrating BirdNET segmentation, HDBSCAN vocabulary clustering, and MRM/PGLS inference.
* **lorg:** A bioinformatics toolkit of over 100 utilities spanning conservation genomics, CRISPR engineering, ancient DNA processing, and de-extinction modelling.
* **Wet Lab and Core Skills:** PCR amplification, DNA barcoding (COI sequence analysis), nucleic acid extraction, and sequence alignment (BLAST). Completed the full Rosalind bioinformatics problem set.
